# Runtime Components

This repository contains my personal configuration files (RC files) and dotfiles for bash, zsh, vim, git, and gdb. 

## Included Files
- `.bashrc`: Bash shell configuration
- `.zshrc`: Zsh shell configuration
- `.vimrc`: Vim editor setup
- `.gdbinit`: GDB debugger preferences
- `.gitconfig`: Git aliases and core settings
- `install.sh`: Script to automatically install these components on a new machine
